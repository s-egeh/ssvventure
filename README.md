# ssvventure

SSV Ventures - Global Trade and Logistics Website

## About
A professional website for SSV Ventures, showcasing global trade, logistics, import/export services, and manufacturing representation.

## Features
- Responsive design with Tailwind CSS
- Hero slider with multiple slides
- Team member profiles with modals
- Contact form integration with Formspree
- WhatsApp floating button
- Animated sections with AOS library
- Modern glassmorphism UI elements

## Technologies Used
- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (Vanilla)
- Font Awesome Icons
- AOS (Animate On Scroll)
- Google Fonts (Poppins)

## Setup
Simply open `index.html` in a web browser to view the website.
